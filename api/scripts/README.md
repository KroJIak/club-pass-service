# API Scripts

## init_db.py

Скрипт для инициализации базы данных. Проверяет наличие таблиц и создает их при первом запуске, если они не существуют.

### Автоматический запуск

Скрипт автоматически запускается при старте `docker-compose up` через сервис `db-init`. Он выполняется один раз перед запуском API и expiration-service.

### Ручной запуск

```bash
# Вручную
python -m api.scripts.init_db

# Через Docker
docker compose exec api python -m api.scripts.init_db
```

### Логика работы

1. Проверяет подключение к базе данных (с повторными попытками)
2. Проверяет наличие таблиц в базе данных
3. Если таблицы отсутствуют - создает их на основе моделей SQLAlchemy
4. Если таблицы уже существуют - пропускает создание

## seed_data.py

Скрипт для заполнения базы данных тестовыми данными.

### Запуск

```bash
# Вручную
python api/scripts/seed_data.py

# Через Docker
docker compose exec api python api/scripts/seed_data.py
```

---

**Примечание**: Проверка просроченных билетов теперь выполняется отдельным независимым сервисом `expiration-service`. См. `expiration-service/README.md` для подробностей.
