# Ticket Expiration Service

Отдельный сервис для автоматической проверки и пометки просроченных билетов.

## Описание

Сервис работает в фоновом режиме и периодически проверяет все активные билеты на предмет истечения срока действия. Билеты, срок действия которых истек, автоматически помечаются как `EXPIRED`.

## Логика просрочки

- Если мероприятие в 00:00-11:59, билет истекает в 12:00 того же дня
- Если мероприятие в 12:00-23:59, билет истекает в 12:00 следующего дня

## Конфигурация

### Переменные окружения

- `DB_HOST` - хост базы данных (по умолчанию: `db`)
- `DB_PORT` - порт базы данных (по умолчанию: `5432`)
- `DB_USER` - пользователь БД (по умолчанию: `postgres`)
- `DB_PASSWORD` - пароль БД
- `DB_NAME` - имя БД (по умолчанию: `club_pass`)
- `CHECK_INTERVAL_MINUTES` - интервал проверки в минутах (по умолчанию: `30`)

## Запуск

### Через Docker Compose

```bash
docker compose up expiration
```

### Вручную

```bash
cd expiration-service
pip install -r requirements.txt
python main.py
```

## Логирование

Сервис выводит подробные логи о каждой проверке:
- Время начала проверки
- Количество помеченных как просроченные билетов
- Ошибки, если они возникают

## Мониторинг

Сервис работает непрерывно и автоматически перезапускается при сбоях (благодаря `restart: unless-stopped` в docker-compose).
